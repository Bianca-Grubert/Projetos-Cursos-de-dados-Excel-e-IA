# 📊 Ferramenta de Análise de Investimentos em Excel

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma **Ferramenta de Análise de Investimentos utilizando o Microsoft Excel**, criada com o objetivo de aplicar conceitos financeiros e recursos de planilhas eletrônicas na simulação de investimentos.

A ferramenta permite realizar projeções a partir de diferentes parâmetros, auxiliando na visualização da evolução de um investimento ao longo do tempo e na análise de possíveis resultados.

O projeto foi desenvolvido como parte de um desafio prático, permitindo aplicar conhecimentos de **Excel, matemática financeira, organização de dados e análise de investimentos**.

---

## 🎯 Objetivo

O principal objetivo da ferramenta é facilitar a simulação de investimentos por meio de uma planilha automatizada, permitindo que o usuário informe diferentes parâmetros e visualize os resultados projetados.

Dessa forma, a ferramenta busca transformar cálculos financeiros em informações mais acessíveis e organizadas para apoiar a análise de diferentes cenários de investimento.

---

## ⚙️ Funcionalidades

A ferramenta desenvolvida permite:

- 💰 Informar valores destinados ao investimento;
- 📅 Trabalhar com diferentes períodos de investimento;
- 📈 Realizar projeções de crescimento patrimonial;
- 💵 Estimar resultados relacionados aos investimentos;
- 🧮 Aplicar cálculos financeiros de forma automatizada;
- 📊 Visualizar projeções para diferentes horizontes de tempo;
- 🏢 Analisar possibilidades relacionadas a Fundos de Investimento Imobiliário (FIIs);
- 👤 Considerar diferentes perfis de investidor;
- 🔎 Comparar cenários para auxiliar na análise dos resultados.

---

## 👤 Perfis de investidor

A ferramenta considera diferentes perfis de investimento:

**Conservador:** prioriza maior segurança e menor exposição ao risco.

**Moderado:** busca equilíbrio entre segurança e potencial de retorno.

**Agressivo:** considera maior exposição ao risco em busca de maior potencial de retorno.

A utilização desses perfis permite trabalhar diferentes possibilidades de distribuição dos investimentos e analisar cenários de acordo com as características do investidor.

---

## 📈 Simulação de investimentos

A ferramenta permite realizar projeções considerando informações fornecidas pelo usuário.

A partir desses dados, os cálculos são realizados automaticamente pelo Excel, permitindo visualizar a possível evolução do patrimônio ao longo do período analisado.

Esse processo facilita a comparação entre diferentes cenários e demonstra, de maneira prática, o impacto de fatores como **tempo, aportes e rentabilidade** sobre um investimento.

---

## 💵 Projeção de dividendos

A planilha também possibilita trabalhar com estimativas relacionadas ao recebimento de dividendos.

Essa funcionalidade permite visualizar possíveis resultados decorrentes dos investimentos e compreender melhor a relação entre patrimônio acumulado e geração de renda.

---

## 🏢 Análise de FIIs

Outro recurso presente na ferramenta é a análise relacionada aos **Fundos de Investimento Imobiliário (FIIs)**.

A estrutura permite trabalhar diferentes possibilidades de distribuição dos investimentos conforme o perfil selecionado, auxiliando na construção e comparação de cenários.

## 🚀 Como utilizar

1. Faça o download do arquivo **Ferramenta de Análise de Investimento.xlsx**.
2. Abra o arquivo no Microsoft Excel.
3. Preencha os campos destinados aos dados da simulação.
4. Selecione ou informe os parâmetros desejados.
5. Acompanhe os resultados calculados automaticamente pela ferramenta.
6. Compare os diferentes cenários apresentados.
